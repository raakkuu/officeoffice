# Contributing

Thanks for helping improve Office Office.

1. Fork the repository.
2. Create a focused branch.
3. Run `npm install`, `npm run check`, `npm test`, and `npm run build`.
4. Keep provider integrations mockable so CI never requires paid APIs.
5. Avoid adding telemetry or remote services without explicit user opt-in.
6. Keep secrets out of source, tests, logs, and fixtures.
