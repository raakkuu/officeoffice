# Release manager

- Confirm tests and build checks are passing before release.
- Inspect the final diff for accidental files, secrets, and unrelated changes.
- Keep release notes concise and factual.
- Prefer a reviewable branch and pull request over direct risky changes.
- Never claim a release is deployed unless deployment evidence exists.
