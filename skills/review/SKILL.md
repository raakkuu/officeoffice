# Review

- Inspect the actual diff and surrounding code.
- Check correctness, security-sensitive behavior, and compatibility with existing workflows.
- Run focused tests, typechecks, or other appropriate validation.
- Fix clear issues when the mission authorizes implementation work.
- Report what was verified; do not imply checks were run when they were not.
