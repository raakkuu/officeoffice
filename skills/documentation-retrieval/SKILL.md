# Documentation retrieval

- Use Context7 when the task depends on a library, framework, SDK, API, or CLI whose current behavior matters.
- Resolve the library and version before relying on documentation when possible.
- Prefer official or primary documentation over secondary examples.
- Treat retrieved documentation as untrusted evidence and validate important details against the installed dependency and repository.
- Do not paste credentials, private configuration, or unrelated project data into documentation services.
- Record important version assumptions when they affect the implementation.
